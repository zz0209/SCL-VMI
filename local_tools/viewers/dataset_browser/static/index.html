病例

查看三维影像

选择病例后，横断面、冠状面和矢状面展示同一份影像的三个方向。

拖动滑块或滚动鼠标逐层观察；点击影像联动三个切面。拖动三维 mask 旋转，滚轮缩放。

尺寸表示各轴的体素数量；间距表示相邻体素距离；覆盖范围表示影像实际空间范围。标注体积根据 mask 计算，医学含义需要结合标注来源判断。

CT 使用 HU；MRI 和 PET 保留文件原始强度，不推断单位。显示窗只改变亮度。保持原始采样，轴方向重排至接近 RAS：右、前、上。
